# PDF Report Settings

PDF output is configured through **web report templates** in **Assessments → Reports**. Open the intended template, choose its report settings, and configure the content and presentation used by the report.

## Choose the output method

- **Browser printing** is the default. Readers use Print or their browser’s Print command and choose Save as PDF.
- **AI PDF** requires an explicit opt-in in that report’s settings. Configure the available density and detail options, then generate a PDF from the report’s controls.

Check branding, cover sections, and table-of-contents options in the report template. Detailed contents subheadings can be enabled separately; readers can expand or collapse detailed entries when present.

## Check the assessment-specific result

Preview with the intended assessment and verify the organization’s identity, start and closing dates, saved notes, recommendations, and Plan of Action. Inspect the resulting PDF before distribution.

For client access, use **Account → Reports** and check the report entry for the specific assessment. A reusable template and a generated PDF are different: changing a template does not rewrite a PDF that has already been generated.

The legacy PDF template editor has been retired. Use [Web Reports](web-reports.md) for design and [PDF Reports](../assessments/pdf-reports.md) for generation and sharing.
