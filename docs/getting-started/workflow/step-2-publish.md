# Start response collection

Starting collection is part of **Deliver → Deliver to respondents** in the current Getting Started page. Follow [Deliver to respondents](step-3-deliver.md) for the complete guide.

1. Open the assigned assessment and review its questions, recipients, response target, dates, and evidence settings while it is **Draft**.
2. Change its status to **In Progress** when it is ready for responses.
3. If start and end dates are set, confirm that today is within that window.
4. Share the anonymous link or personalized recipient invitations, then monitor progress.
5. Move to **Results Review** after collection finishes.

Publishing a reusable Library template and starting an account assessment are separate actions. Publish the template before assigning it; start the assigned assessment before asking respondents to participate.
