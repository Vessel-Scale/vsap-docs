# Collaborate on Action Items

Open **Actions** for the relevant account or assessment and select an item. Keep the item’s text, status, priority, due date, and comments current so the client and delivery team can follow the agreed work.

## Record useful updates

Add comments that explain decisions, progress, blockers, and the basis for impact estimates. Refer to the assessment and category context when explaining why an action matters. Record the next step and timing when responsibility or scope changes.

Use the visibility controls offered in the comment form. Check the audience before adding internal discussion or client-facing updates. Available comment controls depend on your permissions and portal configuration.

## Link project work

If delivery is managed in another system, add the item’s **Project Link** and an optional readable link label. Use a link the intended team can access, then keep the Action Tracker’s summary and status aligned with that work.

## Maintain the handoff

The initial selected recommendations and Plan of Action arrive at first assessment closure. Subsequent discussion and changes belong in the tracker: reclosing an assessment does not regenerate its items. Add further work with **Add Item** and use **Global Items** for assessment-level priorities or implementation details.
