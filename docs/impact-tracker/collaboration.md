# Collaboration & Comments

The Impact Tracker includes built-in collaboration features allowing team members and clients to communicate about action items, share progress updates, and maintain a complete audit trail.

## Comment Types

### Internal Comments
Comments visible only to your internal team:
- Team coordination and task updates
- Technical notes and implementation details
- Internal status reviews
- Private strategic discussions

**Who can see:** Account executives, managers, admins, and team members within your organization

### Client-Facing Comments
Comments shared with the account's client users:
- Progress updates on action item implementation
- Requested information or documentation
- Milestone announcements
- Public status changes

**Who can see:** Your team + authorized users from the client organization

## Adding Comments

1. Open an action item from the Impact Tracker
2. Scroll to the **Comments** or **Activity** section
3. Click **Add Comment**
4. Enter your message
5. Toggle visibility:
   - **Internal Only** — Visible to your team only
   - **Share with Client** — Visible to client users
6. Click **Post**

## Notification & Mentions

You can mention team members or clients to get their attention:

- Type `@` to mention a person by name
- Mentioned users receive notifications
- Mentioned comments are highlighted
- Great for assigning tasks or requesting updates

## Activity Timeline

View a complete history of all changes to an action item:
- **Status changes** — Who changed status and when
- **Impact metric updates** — What metrics were added or modified
- **Assignment changes** — When responsibility changed hands
- **Comments** — All team and client communications
- **Attachment uploads** — Supporting documentation added

This provides full audit trail and context for every action item.

## Best Practices for Collaboration

### For Account Executives
- **Keep Clients Informed** — Use client-facing comments for regular progress updates
- **Acknowledge Issues** — Respond to client comments within 24 hours
- **Celebrate Wins** — Share completion announcements publicly
- **Request Information** — Use comments to ask for impact data or supporting documentation

### For Clients
- **Provide Updates** — Comment with progress as work is completed
- **Report Blockers** — Immediately communicate any obstacles or issues
- **Share Evidence** — Attach documentation proving impact metrics
- **Ask Questions** — Use comments to clarify expectations or timelines

### For All Users
- **Be Specific** — Reference dates, metrics, or findings when relevant
- **Respond Timely** — Check assigned actions daily and respond to mentions
- **Keep Records** — Important decisions or commitments in comments create accountability
- **Use Formatting** — Bold important items, use line breaks for clarity
- **Attach Evidence** — Include photos, spreadsheets, or documentation as proof of impact

## Email Notifications

Stay informed about action item updates:
- Get emailed when you're mentioned in a comment
- Receive notifications when assigned to an action item
- Get updates when action status changes
- Notification preferences can be configured in account settings
