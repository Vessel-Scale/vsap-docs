# Available Assessments

Browse the client **Library** to find assessment types you can start. The current navigation separates **Library**, a catalog of templates, from **Assessments**, the work already assigned to or created by your account.

Search or filter the Library, select a type, review its description, and choose **Create This Assessment for My Account** when available. Your account and selected type are prefilled. Save the draft and return through Assessments to continue.

Only templates made visible to clients by an administrator appear. A staff Library template or a Shared Template Library item is not automatically available here. Contact your account executive when you need a different template.

Some older layouts grouped this catalog under All Available Assessments. Use the Library guide for the current workflow.
