# PDF Reports

Create a PDF from the assessment’s web report. Browser printing is the default; AI PDF generation is available only when explicitly enabled for that web report.

## Print to PDF

1. Save the assessment’s analysis and recommendations.
2. Open the intended web report and check the account, assessment dates, branding, and content.
3. Choose **Print** when offered, or use your browser’s Print command.
4. Select **Save as PDF** and inspect page size, margins, backgrounds, and page breaks before saving.

Printing uses the web report’s print layout and does not run AI generation.

## Generate an AI PDF

When the report’s settings enable AI PDF, use the **AI PDF** option in the report controls or its **PDF** button. Choose the available density and detail options and wait for generation to complete. Review the generated document before downloading or sharing it.

A generated PDF is a saved output. After changing analysis or the report design, generate a new PDF if you want those changes reflected. Use **Share Report** to select an available stored PDF when sharing.

## Configure content and access

Administrators manage the reusable report in **Assessments → Reports**. Report settings control branding, cover content, table of contents, and AI PDF options. **Account → Reports** manages client availability for the report associated with an individual assessment.

The retired legacy PDF template editor is no longer the setup workflow. See [PDF report settings](../settings/pdf-reports.md) for the current approach.
