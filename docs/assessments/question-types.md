# Assessment Question Types

Assessment questionnaires use the response types configured in their Library template. They can include text, numeric, numeric range, multiple choice, preset scales such as Likert or binary choices, and multiple select.

See the [question type reference](../library/question-types.md) for configuration, examples, and scoring behavior. Clients answer the supplied questions; staff adapt reusable content through the Library editor.

Where evidence is enabled, supporting files belong to the relevant question. Respondents can preview and delete their own draft uploads before submission, and reviewers can inspect evidence alongside answers.

Where conditional rules are configured, a respondent may see follow-up questions, explanations, or sections based on earlier answers. Use the question guidance and complete the visible required fields before submitting. Template authors should test triggering and non-triggering paths in Preview.
